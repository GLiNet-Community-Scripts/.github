# GL.iNet GitHub Community

This organization is an **unofficial community** for open-source GL.iNet and OpenWrt projects.

## Scope

The organization includes community-created and selected upstream projects covering:

- Router scripts, utilities, and dashboards
- VLAN, QoS, VPN, Tailscale, and ZeroTier networking
- AdGuard Home, cellular/SMS, logging, monitoring, and diagnostics
- GLKVM firmware, cloud, desktop, and integration tools
- OpenWrt and GL.iNet documentation
- Community issue tracking and support

## Important disclosure

This organization is not affiliated with, endorsed by, or operated by GL.iNet. Projects retain their original authorship and licenses. Forked repositories should be treated as mirrors or community adaptations unless the repository says otherwise.

## Contributing

Preserve upstream attribution and licensing, document hardware/firmware compatibility, avoid embedding credentials, and explain whether a project is a fork, mirror, or original community work.
